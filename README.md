Full rewrite of <https://pastry.diy> in Luau for [webc](https://git.0x8e.net/t/webcomposer).

## Usage

Install WebComposer if you don't already have it:

```bash
cargo install webcomposer-bin
```

Afterwards, you can start the server with the following command (in the `app` directory):

```bash
webc run
```
